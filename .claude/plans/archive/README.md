# Archive de planos (Claude Code)

> **Para que serve:** Política de arquivamento de planos `.plan.md` no Claude Code.
> **Função:** Preservar histórico de fases, modelos e critérios de encerramento sem apagar.

Mover planos concluídos ou cancelados para `archive/` em vez de deletar.

Preserva histórico de dependências, modelos por fase e critérios de encerramento.
